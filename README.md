# Камень · дневник скалолазных тренировок

Приложение находится в [`app`](app/README.md). Исходные документы программы лежат в корне, а подготовленный пакет — в `app/src/program-package.json`.

Программа содержит личные сведения и встроена в приложение. Сборка в ветке `gh-pages` доступна посетителям сайта вместе с программой, даже если исходный репозиторий приватный. На вкладке «Программа» можно заменить встроенный пакет своим JSON.

Для корректного обновления установленной PWA каждая правка встроенной программы должна повышать поле `version` в `app/src/program-package.json`. Прежняя встроенная версия обновится автоматически; импортированный пользователем файл останется выбранным.

Для запуска и проверки: `cd app && npm ci && npm test && npm run build`. Для обновления сайта сборка выполняется с `VITE_BASE=/climb_plan/`, после чего содержимое `app/dist` отправляется в ветку `gh-pages`.
