# Камень · дневник скалолазных тренировок

Локальная PWA для iPhone. Основной экран — календарь. Нажатие на день открывает отдельную страницу с целью, единым блоком тренировки с планом и свободными заметками о лазании и ОФП, оценками после занятия и следующим утром. Числовые оценки и длительность выбираются из меню; поля сохраняются автоматически. Вкладка «Программа» позволяет импортировать JSON, а её шаблон можно скачать прямо в приложении.

## Запуск и проверка

Из папки `app`:

```sh
npm ci
npm run dev
npm test
npm run build
npm run test:e2e
```

Для браузерных тестов нужен Chrome или Chromium. На macOS используется установленный Chrome; в другой системе можно выполнить `npx playwright install chromium` либо указать `PLAYWRIGHT_CHROME_PATH`.

## Где лежат данные

Записи и импортированная программа сохраняются в базе **IndexedDB внутри установленной PWA на телефоне**. При повторном открытии приложения они остаются на месте и доступны без сети после загрузки офлайн-ресурсов. Сайт не имеет аккаунта и сервера с дневником. Сохранение записи подтверждается надписью «Сохранено на устройстве».

Это локальное хранилище может исчезнуть, если удалить PWA или её данные. Поэтому в настройках есть «Сохранить копию JSON»: выбери в системном меню «Сохранить в Файлы» → iCloud Drive. Файл попадёт в iCloud как обычный документ. **Копия создаётся только вручную**; новые записи не появляются в ней сами. Периодически сохраняй новый файл и проверяй его наличие в «Файлах». Восстановление из JSON полностью заменяет данные PWA после просмотра содержимого и подтверждения.

Safari и иконка установленной PWA могут иметь разные локальные хранилища. Веди дневник через иконку на главном экране. При смене адреса сайта перенос делается через экспорт и восстановление копии.

При обновлении старой версии подробные тренировки превращаются в свободный текст дня. Исходные подробные записи остаются в базе и входят в резервную копию как архив. Старые резервные копии версии 1 также принимаются.

## Программа

Персональная программа встроена в приложение и появляется при первом запуске. На вкладке «Программа» можно скачать нейтральный [пустой шаблон](public/program-template.json) и заменить встроенный пакет другим JSON. Пакет из исходных документов пересобирается локально:

```sh
python3 scripts/extract_program.py
```

Он создаётся в `src/program-package.json` и **включается в публичную сборку**. Поэтому посетитель сайта может получить этот файл из JavaScript-кода приложения. Выбор тренировки в дне показывает упражнения и дозировки рядом со свободным текстом факта; он не создаёт записи по календарю автоматически.

## Публикация и установка на iPhone

Ветка `gh-pages` содержит только собранное приложение из `app/dist`. В настройках репозитория выбери Pages → Source: Deploy from a branch → `gh-pages` → `/ (root)`. Постоянный HTTPS-адрес будет вида `https://<имя пользователя>.github.io/<имя репозитория>/`. Для обновления ветки приложение нужно собрать с `VITE_BASE=/<имя репозитория>/`.

Сайт GitHub Pages обычно доступен всем по URL даже из приватного Git-репозитория. Встроенная программа видна посетителям сайта; записи дневника остаются только на телефоне. Резервные копии дневника в Git не добавляй.

На iPhone открой опубликованный адрес в Safari → «Поделиться» → «На экран Домой» → включи «Открывать как веб-приложение», если появится такой переключатель. Запусти приложение **с иконки**, проверь встроенную программу, создай пробную запись, проверь её после закрытия и открытия, затем сохрани первую копию в «Файлы»/iCloud Drive. После первого открытия проверь работу в авиарежиме. Не меняй адрес опубликованного сайта без экспорта копии.

## Структура

- `src/App.tsx` — календарь, редактор дня, программа и настройки.
- `src/model.ts` — формат дня, программы и преобразование старых записей.
- `src/program-package.json` — встроенная программа из исходных документов.
- `src/storage.ts` — база IndexedDB, импорт и резервные копии.
- `src/style.css` — стили.
- `public/` — иконки и нейтральный шаблон JSON.
- `scripts/extract_program.py` — локальная подготовка персональной программы.

Пользовательский интерфейс не содержит страницы итогов, форм отдельных трасс и подходов, собственного конструктора шаблонов и статусов тренировки. Тесты и конфигурация сборки оставлены для безопасного обновления PWA.
