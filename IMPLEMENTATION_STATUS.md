# Состояние реализации · 22.09.2026

Выполнено упрощение интерфейса: календарь стал основной и первой вкладкой, записи помечены точками, день открывается как отдельная страница с возвратом свайпом вправо. В дне остались необязательная цель, единый блок с выбором программы и свободным текстом для лазания и ОФП, оценки после занятия и следующего утра. Числа выбираются из меню. Подсказка о свайпе убрана; знак в шапке и иконках PWA заменён на скалу. Отдельные формы упражнений, выбор отдыха, кнопка завершения, поле гипотезы и раздел итогов удалены.

Программа открывается автоматически из встроенного JSON и может быть заменена импортом на своей вкладке; нейтральный шаблон скачивается там же. В `src` находятся четыре файла кода и пакет `program-package.json`.

Данные остаются в IndexedDB установленной PWA. Старые записи преобразуются в свободный текст, а исходная подробная форма остаётся в архиве базы и резервной копии. Принимаются копии старого и нового формата. Экспорт в «Файлы»/iCloud Drive ручной; автоматической синхронизации нет.

Проверено: `npm test` — 6/6; `npm run build` — успешно; `npm run test:e2e` — 3/3 в Chrome (импорт, сохранение, календарная отметка, офлайн, экспорт/восстановление, старая копия, мобильная ширина и свайп).

Проект подготовлен как репозиторий `tyutenkovve/climb_plan`. Исходная программа, таблица и встроенный JSON входят в приватный Git; отдельная ветка `gh-pages` содержит собранное приложение с этой программой. Публикация GitHub Pages требует включения Pages для репозитория и проверки доступности тарифа. На реальном iPhone ещё нужно проверить установку из Safari, работу в авиарежиме, системное меню «Файлы» и удобство экранной клавиатуры.
